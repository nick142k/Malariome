About MalariaAI

MalariaAI is an academic research project that screens microscopic blood-cell images for malaria parasites with deep learning and explains its output with Grad-CAM. It classifies a single cell image as Parasitized or Uninfected.

Method in brief

  • Trained on the public Kaggle dataset "Cell Images for Detecting Malaria", using a patient-level split so that cells from one patient never appear in more than one of train, validation and test.
  • A custom CNN trained from scratch was compared with a fine-tuned MobileNetV2 transfer-learning model.
  • The decision threshold was chosen on validation data only; the test set was kept locked until the final evaluation.

Limitations

  • Not clinically validated and not a diagnostic device.
  • Trained on one dataset: other microscopes, stains, preparations or image qualities may behave differently.
  • Designed for single-cell crops, not whole slides.

Attribution

Reference baseline: afloresep/CNN-Malaria-Detection (used as a reference only; this implementation is new). Dataset: Kaggle, "Cell Images for Detecting Malaria".

Privacy

The history stores only the file name, the model output, the threshold, the model version and a timestamp. Uploaded images are deleted automatically.
